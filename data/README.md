# Data

`customer-data.csv` holds JCD's loyalty program records for 102,539 customers: demographics, visit recency, and six-month purchase counts, spend and margin by department (apparel, electronics, health & beauty, housewares). It also includes `response_flag` (whether the customer responded to a promotion in the last 12 months).

The file was shared by the company for coursework, so it is not included in this repository. Put a copy here to run the scripts in `src/`.
